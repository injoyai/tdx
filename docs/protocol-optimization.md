# protocol 编解码与聚合约定

`protocol` 的正常响应解码保持价格尺度、成交量口径、记录顺序、时间和空列表形状。性能优化不改变请求帧字节，不根据字段名称猜测扩展市场单位。

## 基础转换

- `Uint16`、`Uint32` 保留原转换器的补零和截取规则，包括不足固定宽度以及超过 8 字节的输入；协议内部应传对应宽度的字段。
- `Float32` 读取前 4 字节的 IEEE 754 位模式，短输入返回 0；保留负零、无穷和 NaN 位模式。
- `GBKToUTF8` 直接解码已有字节，保留非法/截断 GBK 的替代行为并移除 NUL，不修改输入。
- 变长数值和固定字段的读取继续执行边界检查。批量结果只在最小记录长度通过校验后预分配；原返回 `null` 的空列表不改为 `[]`。

## 畸形响应

- 集合竞价声明的记录数必须有完整的 16 字节记录，否则返回错误，不发生切片越界。
- `ParseBlockFile` 要求完整的 2813 字节板块记录，每块成分数最多 400。截断或成分数越界时返回错误，不返回部分板块。`StConn.GetBlockData` 传播该错误；不保留忽略解码错误的旧签名。
- `ReadFrom` 支持短读、连续帧及任意字节位置的帧头恢复。返回当前完整帧，不消费下一帧；截断帧返回读取错误。

## K 线聚合

- `Klines.Kline` 和 `Merge` 保留首根 `Last`，累计 `Order`、成交量和成交额；OHLC 与周期结束时间沿用原聚合规则。
- 涨跌家数是时点快照，取周期末根的值。`Merge241` 的补齐分钟沿用此前最近快照；不能把不同分钟的上涨、下跌家数累加。
- 沪深 241 根分钟网格为 09:30、09:31～11:30、13:01～15:00。`Merge241` 保留独立的 09:30 竞价，再从 09:31 起合并。分笔合成和周期合并共用这个网格。
- 周期参数极大时也不允许整数溢出；非正周期保持原行为。`Merge` 对 `n<=1` 保持原切片返回语义。

## 其他边界修正

`FloatUnit` 正确推进“万”“亿”，保留原来的严格大于 10000 的缩放阈值及两级单位上限。`FloatUnitString` 的输出规则保持不变。`I64Sqrt` 对非负 int64 返回向下取整的平方根，负数返回 0，并避免平方比较溢出。

## 验证

```sh
go test ./protocol
go test -race ./protocol
go test ./protocol -run '^$' -fuzz FuzzEncodingLegacyCompatibility -fuzztime=5s -parallel=1
go test ./protocol -run '^$' -bench BenchmarkProtocol -benchmem
```

编码兼容性测试保留 v1.0.0 转换逻辑作为对照，覆盖随机长短输入、异常 GBK、浮点特殊值和输入不可变性。回归测试覆盖逐字节截断、帧重同步、连续帧、板块错误传播、聚合字段及大整数边界。

跨版本比较须使用相同原始响应和相同运行时区，将允许的缺陷修正、既有版本差异与本轮新增差异分别列出。离线固定样本相等不能代替真实行情的独立来源准确性验证。
